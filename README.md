A fast drop-in for csv-reader 1.0.0: reads broken CSV files exactly as the reference does, at about a fifth of its CPU time. A line-based fast path handles clean records (slice the line, split on commas); a field-by-field slow path reproduces every broken-row rule — stray CRs, unterminated quotes, quote junk, short and long rows — with the same errors in the same order.

## Run it

```sh
MAKEFUN_INPUT_DIR=input MAKEFUN_OUTPUT_DIR=output node main.ts
```
